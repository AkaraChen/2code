这份备忘录本来是写给我自己的，现在发出来给你照抄。里面是我 2026 年 8 月在用的 Agent 工作流：装哪些 CLI、目录怎么放、哪些命令值得做成模板、窗口怎么摆。

CLI 生态变得太快，名单那一节我标了核实日期。你读到的时候，请先把它当历史档案看，再决定信不信。

## 我现在装哪些 CLI（2026 年 8 月 3 日核实）

别抄名单，抄思路：主力一个，备胎一个，免费额度大的再备一个。

- **Claude Code**：主力。复杂重构、多文件改动交给它，贵但省心。
- **Codex CLI**：备胎。Claude 限流，或者我想换个脑子的时候用，沙箱里跑命令放心一些。
- **Gemini CLI**：免费额度大，上下文长。扔日志、读大文件、做摘要这种粗活都归它，不心疼。
- **Kimi CLI / Qwen Code**：国内模型系，网络直连不用折腾，中文任务的表达习惯也对味。
- **OpenCode / Aider**：开源、模型无关，接自己的 API key。想省钱，或者想锁死某个模型做对照实验时用。

五个格子不是都要装满。我的实际日常是前三个轮班，后面两个看情况上场。

这个名单的保质期大概三个月。所以下面几节都不绑定具体工具——工具会换，习惯不用换。

## 网络和账号，只说三句话

这一节故意不写教程。任何「手把手教你配 XX」的文章都活不过一个季度，写了就是害人。

- 代理要在终端这一层生效。系统里设了代理，不代表你的 shell、`npm`、agent 都走它。新开终端先确认环境变量真的进来了。
- 账号和付费方案自己评估合规和风险，别照着陌生博客复制命令。
- 第三方 API 中转省钱，但 key 要经过别人的服务器。这件事想清楚再用，公司代码尤其要慎重。

够了。这一节就算过时也不碍事，因为它本来就没写细节。

## 目录：一个项目一个家，worktree 当泳道

我的目录长这样：

```text
~/code/myapp                 # 主 checkout，只用来 review 和合并
~/code/myapp-worktrees/      # 所有任务泳道
  fix-login/                 # 一条任务一个 worktree
  new-sidebar/
  experiment-ai-cache/
```

规矩只有三条：

- **主 checkout 里不写代码。** 它是干净源，合并和发版从这里走，永远处于「随时能给别人看」的状态。
- **一条任务线 = 一个 worktree = 一个分支。** Agent 在里面随便折腾，搞砸了整个目录删掉，成本是零。
- **每个泳道装自己的依赖，起自己的端口。** 端口号写死在模板里，一个泳道一个号，dev server 互不打架。

多项目也一样：一个项目一个家，家的内部再分泳道。别在桌面、下载目录和 /tmp 里随机开项目，三个月后你自己都找不到。

## 哪些命令该固化成模板

判断标准很简单：**一条命令一周敲三次以上，就该变成模板。** 我的清单常年是这四条：

- `pnpm dev`：dev server，端口按泳道固定；
- `claude` 或 `codex`：agent 本体，参数调好后不再手敲；
- `pnpm test --watch`：盯着 agent 刚改完的代码；
- `pnpm install && pnpm build`：新泳道开张时的初始化。

模板的意义不是省键盘，是省脑子。新开一条泳道时，不用回忆这个项目用 npm 还是 pnpm、agent 要带什么参数，点一下就行。2code 的命令模板就是干这个的：把 Claude、dev server、每天都起的脚本存成一键启动，新窗口里直接点。

## 在 2code 里怎么摆

我的摆法：一个项目一个窗口，一条泳道一个 worktree 窗口。每个窗口里固定三个终端——agent、dev server、测试，顺序永远一样。肌肉记忆比任何窗口管理器都可靠。

对这种摆法帮助最大的是两个功能：

- **完成提醒**：agent 跑完亮绿点、响一声。不用每隔几分钟切一圈窗口看「谁好了」，轮询这件事还给电脑。
- **会话恢复**：重启、关机之后，窗口、终端、历史都还在。半截的 agent 会话和半截的 dev server 不用重新摆一遍。

## 照抄清单

可以直接执行的版本：

- [ ] 装 CLI：主力一个、备胎一个、免费额度大的一个，别贪多；
- [ ] 新开终端，确认代理环境变量真的生效；
- [ ] 主 checkout 只用于 review 和合并，任务全部进 worktree；
- [ ] 每个泳道固定端口，写进模板；
- [ ] dev server、agent、测试、初始化，四条命令做成模板；
- [ ] 窗口布局固定：agent / server / test，顺序不变；
- [ ] 打开 agent 完成提醒，停止人肉轮询。
