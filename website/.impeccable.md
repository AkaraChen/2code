## Design Context

### Users
Developers who live in terminals and run several coding agents (Claude Code, Codex, …) at once, across projects and git worktrees. Many arrive from Herdr: 2code is a layout for it, not a standalone app. They are allergic to AI-startup marketing and want to see the actual tool.

### Brand Personality
Calm, precise, honest about being young. A serious tool for focused builders: confident without hype, technical without looking cold.

### Aesthetic Direction — "Lanes & Signals"
A sibling of herdr.dev, drawn in 2code's own colours. It borrows Herdr's grammar: a two-tone headline whose second line is gray, README-like chapters headed `## …`, product UI drawn in HTML, an install prompt with a Copy button, and hairline FAQ and footer. It keeps its own identity: light-first with an equal dark theme, and the 2code sidebar as the page's table of contents.

- **Surfaces and ink** come straight from `themes/2code-light.json` and `2code-dark.json` (shadcn neutral). Light and dark are one token set via `light-dark()`.
- **The only colour is agent status**: working `#34d399` (pulsing), needs you `#facc15`, done `#22c55e`. Use them for status and nothing else. The rail uses them for reading progress, and "Needs you" sits on Install.
- **Type**: Instrument Sans (variable, headlines at ~88–94% width, tight tracking); JetBrains Mono only where the content is code, a command, a branch name or a keycap. CJK falls back to the system face with no negative tracking.
- **Signature**: the sticky chapter rail looks like 2code's project sidebar, with one profile per chapter and status dots that turn green as you read. Each chapter shows a piece of the app drawn in HTML (`app/app-mocks.tsx`), labelled with the app's own wording in both languages.

### Design Principles
- The product is the hero: one real screenshot up top, then HTML-drawn app parts that stay sharp, follow the theme and translate.
- The site and the app should look like the same piece of software (radii, borders, buttons, labels).
- Emphasis by brightness, not weight: `**phrase**` in copy renders as `--ink` within `--ink-2` text.
- Keyboard-first: primary CTAs advertise their shortcut with a keycap.
- Motion only where it means something: status dots, one setup run that plays when it scrolls in, gentle reveals. All off under `prefers-reduced-motion`.

### Non-negotiables
- Radii 5–12px (app-like), solid near-black primary button, hairline borders. No gradients, no glow, no glassmorphism, no colour-blocked panels.
- Status colours never decorate.
- Light and dark are equal citizens; the system decides unless the visitor overrides it.
- Claims must be verifiable today (README is the source). No invented metrics, stars or user counts.
